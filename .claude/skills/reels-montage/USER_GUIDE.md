# Как пользоваться скиллом `reels-montage`

## Установка (один раз)

1. Скопируй папку `reels-montage/` (с `SKILL.md` внутри) в `~/.claude/skills/` —
   тогда скилл будет доступен в любом проекте. Либо оставь её в `.claude/skills/`
   этого репозитория — тогда он работает только здесь.
2. Запусти Claude Code и напиши «смонтируй ролик». При первом запуске Claude сам
   проверит/установит `ffmpeg` и whisper и создаст папку `reels/` на Рабочем столе.

## Что разложить по папкам `reels/`

| Папка | Что положить |
|---|---|
| `library/` | полоски (в имени `strip` или `полоски`) и градиент (`gradient` / `градиент`), мемы |
| `fonts/` | 3 шрифта: заголовочный condensed, субтитровый sans, рукописный |
| `stickers/` | одна PNG-иконка без фона — стоит у субтитров весь ролик |
| `music/` | фоновые треки mp3 |
| `sfx/` | короткие звуки появления: свуш, поп |
| `context_assets/` | постоянные вставки на все ролики (скрины, демо-видео) |

Эти папки Claude никогда не чистит.

## Каждый новый ролик

1. Положи сырое видео в `input/`, одноразовые вставки — в `inserts/`.
2. Напиши ТЗ, например:

```
смонтируй ролик
ХУК: Как монтировать reels через claude
КОДОВОЕ СЛОВО: монтаж
когда говорю про статистику — покажи скрин со статистикой
фуллскрин demo.mp4
МУЗЫКА: lofi
ЦЕНЗУРА: деньги, заработок
```

3. Готовый ролик появится в `output/<тема>-final.mp4`, исходники переедут в `done/`.
   Claude пришлёт отчёт: длительность до/после, какие вставки куда поставлены и чего
   не хватило.

Все строки ТЗ, кроме «смонтируй ролик», необязательны — без них Claude смонтирует
по шаблону и сам подберёт вставки из `context_assets/` по смыслу.
