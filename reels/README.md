# reels/ — рабочие папки скилла `reels-montage`

| Папка | Что тут | Сейчас |
|---|---|---|
| `input/` | сырое видео текущего ролика | — |
| `inserts/` | вставки только для текущего ролика | — |
| `context_assets/` | постоянные вставки на все ролики | — |
| `library/` | `полоски.png` (лента сверху), `градиент.png` (затемнение снизу), мемы | **нужно положить** |
| `stickers/` | PNG-иконка без фона у субтитров | **нужно положить** |
| `music/` | фоновая музыка | `flashing lights.mp3` |
| `sfx/` | звуки появления вставок (свуш, поп) | **нужно положить** |
| `fonts/` | заголовки / субтитры / рукописный | `Heading Now Extrabold.ttf`, `HelveticaNeue-Roman.otf`, `denistina_en.ttf` |
| `done/` | использованные исходники | — |
| `output/` | готовые ролики `<тема>-final.mp4` | — |

Храни их локально; в git лежит только структура.
