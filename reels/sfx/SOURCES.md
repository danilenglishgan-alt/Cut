# Звуки sfx/

| Файл | Что это | Для чего | Источник / лицензия |
|---|---|---|---|
| `swoosh_1.wav` | короткий свуш 0.32s, быстрая атака | появление скринов/фото | синтезирован (фильтрованный шум), свободно |
| `swoosh_2.wav` | мягкий свуш 0.45s | фуллскрин-переключение, крупные вставки | синтезирован, свободно |
| `pop_1.wav` | мягкий поп 0.14s | стикеры / PNG без фона | синтезирован, свободно |
| `pop_2.wav` | поп 0.19s (Kenney `drop_002`) | стикеры | [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), CC0 |
| `pop_3.wav` | поп 0.28s (Kenney `drop_004`) | стикеры | [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds), CC0 |

Во всех файлах транзиент в самом начале (≤15ms): скилл ставит его на первый кадр появления вставки.
Пик нормализован до −1 dBFS, при сведении скилл опускает звуки до ≈ −13 dB.
